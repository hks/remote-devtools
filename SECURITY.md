# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/hks/remote-devtools/security/advisories/new), not in public issues.
Include the affected component (SDK, relay, UI, desktop app), the version and steps to reproduce.

You can expect an acknowledgement within a week. Fixes are released for the latest version.

The [security guide](https://hks.github.io/remote-devtools/guide/security) describes what Remote DevTools protects and
what it does not (for example, the UI has no login yet).
